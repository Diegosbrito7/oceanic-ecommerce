# OCEANIC – E-commerce
Proyecto e-commerce OCEANIC - Rolling Code


Proyecto desarrollado en el marco del curso de Rolling Code.

Descripción

OCEANIC es una tienda online de indumentaria y accesorios. El proyecto busca desarrollar una interfaz web sencilla, moderna y adaptable a distintos dispositivos.

CSS
